## ২. থ্রেট মডেল ও ঝুঁকি মূল্যায়ন (Contextual Threat Modeling)

NEO-WILDER V4 একটি ট্রেডিং এক্সিকিউশন বট নয়; এটি একটি **স্থায়ী সিগন্যাল-অনলি (Permanent SIGNAL_ONLY) মনোলিথ**। এর আর্কিটেকচারাল বৈশিষ্ট্যগুলোর কারণে শনাক্তকৃত ভালনারেবিলিটিগুলোর ক্ষতিকর প্রভাব বাস্তব ক্ষেত্রে সম্পূর্ণ নিরপেক্ষ:

| ফ্যাক্টর | অ্যাপ্লিকেশনের বাস্তব অবস্থা | ঝুঁকি প্রশমন মূল্যায়ন |
|---|---|---|
| **নেটওয়ার্ক ইনগ্রিস (Ingress)** | অ্যাপ্লিকেশনে কোনো HTTP/REST সার্ভার বা লিসেনিং পোর্ট নেই। কোনো ইনকামিং ওয়েবহুক খোলা নেই। | রিমোট অ্যাটাকার অ্যাপ্লিকেশনটিতে সরাসরি কোনো নেটওয়ার্ক প্যাকেট বা রিকোয়েস্ট পাঠাতে পারে না। |
| **আউটবাউন্ড কানেকশন** | শুধুমাত্র বিশ্বস্ত পাবলিক এপিআইতে আউটবাউন্ড কানেকশন (`wss://stream.binance.com`, `https://api.binance.com`, `https://public.coindcx.com`)। | কোনো আনট্রাস্টেড তৃতীয় পক্ষের সার্ভারে রিকোয়েস্ট পাঠানো হয় না। |
| **প্রাইভেট কী বা ফান্ড** | সিস্টেমে কোনো প্রাইভেট এপিআই কী, সিক্রেট কী বা ওয়ালেট নেই। | কোড এক্সিকিউশন ভালনারেবিলিটি থাকলেও তহবিল চুরি বা ফেক অর্ডার এক্সিকিউশনের সুযোগ নেই। |
| **ডেভেলপমেন্ট টুলিং** | `gitpython`, `black`, `setuptools`, `pip` রানটাইম সিগন্যাল পাইপলাইনে অংশগ্রহণ করে না। | এই টুলগুলোর ত্রুটি প্রোডাকশন সিগন্যাল জেনারেশনকে প্রভাবিত করতে পারে না। |

## ৪. প্রোডাকশন স্ট্যাজিং ও হার্ডেনিং সুপারিশ (Production Hardening Strategy)

প্রোডাকশন বা ক্লাউড সার্ভারে ডিপ্লয়মেন্টের সময় নিম্নোক্ত হার্ডেনিং প্রোটোকল কঠোরভাবে অনুসরণ করার নির্দেশ দেওয়া হচ্ছে:

1. **আইসোলেটেড ভার্চুয়াল এনভায়রনমেন্ট (.venv):**
   গ্লোবাল পাইথন এনভায়রনমেন্ট ব্যবহার না করে একটি সম্পূর্ণ ফ্রেশ ভার্চুয়াল এনভায়রনমেন্ট তৈরি করা:
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   pip install --upgrade pip setuptools wheel
   ```

2. **লেটেস্ট পিন্ড ডিপেন্ডেন্সি ইনস্টলেশন:**
   নিরাপদ ও প্যাচড সংস্করণ সহ `requirements.txt` থেকে ডিপেন্ডেন্সি ইন্সটল করা:
   ```bash
   pip install "aiohttp>=3.14.4" "urllib3>=2.8.0" "python-dotenv>=1.2.2" pyyaml pydantic
   ```

3. **লিনাক্স সিস্টেমড সার্ভিস সিকিউরিটি কন্টেনমেন্ট:**
   `deployment/systemd/neo-wilder-v4.service` ইউনিটে ইতিমধ্যে নিম্নোক্ত প্রোডাকশন স্যান্ডবক্সিং ফ্ল্যাগসমূহ অন্তর্ভুক্ত রয়েছে:
   - `User=neowilder` (নন-রুট আনপ্রিভিলেজড ইউজার)
   - `NoNewPrivileges=true` (প্রিভিলেজ বৃদ্ধি সম্পূর্ণ নিষিদ্ধ)
   - `ProtectSystem=strict` (পুরো ফাইলসিস্টেম রিড-অনলি)
   - `PrivateTmp=true` (পৃথক আইসোলেটেড টেম্প ডিরেক্টরি)
   - `ProtectHome=true` (হোম ডিরেক্টরি আইসোলেশন)
